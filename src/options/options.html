1. Categories to clean

Choose which kinds of elements get removed when you clean a page.

2. Default mode

"Declutter only" keeps the page's original layout. "Reader mode" rebuilds a fully clean reading view (like Reader View).

When on, switching mode from the popup on a specific site is remembered for that site - other sites keep using the default above.

3. Custom CSS selectors

Advanced: one selector per line. "Always remove" overrides the defaults; "Always keep" blocks removal even if the category is checked.

4. Auto-clean on domains

Pages on this list are cleaned automatically as soon as they load, no click needed. Requires site access permission (you'll be asked when you click the button).

    7. Per-site removals (from "Pick element to remove")
